# isomat

Proof visualizer and math ↔ LLM interface layer.

## Purpose

`isomat` explores the boundary between formal mathematics and large language
models. It provides:

- **Proof visualization** — render mathematical proofs as navigable, step-by-step
  structures rather than dense linear text.
- **Math objects** — first-class representations of mathematical entities
  (statements, definitions, lemmas, proof steps) that can be inspected,
  manipulated, and linked.
- **LLM ↔ math layer** — a translation layer that lets language models read,
  reason about, and emit structured mathematical content, bridging natural
  language and formal representations.

## Goals

- Make proofs legible and explorable.
- Give LLMs a structured surface to work with math instead of raw prose.
- Serve as the foundation other projects in this workspace build on.

## Status
